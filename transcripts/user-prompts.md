## 对话小结（需求方视角的价值）

用户的全部输入中，有 **8 次实质性干预**改变了交付物走向：

1. **"用Java相关成熟的框架"+"华住集团还在用Java8"** → 技术栈从 Boot3/Java17 反转为 Java 8/Boot2.7
2. **opus-4-8 外部复评（8.5/10）** → 触发死锁测试、性能基准、覆盖率、安全实践、扩展性文档五项加固
3. **"可以用ER图直观表示"** → §3.1 改为 Mermaid ER 图
4. **"酒店还有LOS模型"** → 补全 LOS 收益管理约束层（表+策略+10 用例）
5. **"LOS不是价格维度的吗"** → 显式标注单房价码（BAR-only）简化与多房价码演进路径
6. **"每次改动需要新增测试用例+推送远程"** → 确立工程闭环约定（已持久化）
7. **"加锁影响吞吐，能否用乐观锁"** → 防超卖双模式落地（条件原子更新 + OptimisticInventoryTest 同规格证明，47/47）
8. **"ROOM_TYPE 应该叫商品"** → 显式标注"商品=房型×房价码"维度关系与 product 表演进路径
